# Phi Browser Framework

This repository is used to distribute **Phi Browser Framework**, the compiled browser engine that [**Phi Browser**](https://phibrowser.com) is built on. It is a required dependency of the open source Phi Browser clients:

- [phibrowser-mac](https://github.com/phibrowser/phibrowser-mac), Phi Browser for macOS
- [phibrowser-win](https://github.com/phibrowser/phibrowser-win), Phi Browser for Windows

It serves as the distribution source for versioning and publishing the framework artifacts those clients consume. The framework binaries are published under [Releases](https://github.com/phibrowser/phibrowser-framework/releases).
